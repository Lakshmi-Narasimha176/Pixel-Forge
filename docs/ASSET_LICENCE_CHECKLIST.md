# Asset inventory and licence checklist

Maintain one row per imported asset.

| Asset filename | Type | Source/URL | Creator | Licence | Attribution required? | Modifications | Used in level |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

For every asset:
- [ ] Creator and original source recorded.
- [ ] Licence name and version recorded (not just “free”).
- [ ] Commercial/game/jam redistribution rights checked.
- [ ] Attribution wording copied exactly where required.
- [ ] Share-alike, non-commercial, and no-derivatives restrictions reviewed.
- [ ] Font, sound effect, music, texture, model and plugin licences included.
- [ ] Asset is not a ripped or unlicensed game/movie asset.
- [ ] Changes and author-created assets identified.

Do not ship an asset if its origin or redistribution rights are unclear. Keep licence text/screenshots in the submission archive where permitted.
