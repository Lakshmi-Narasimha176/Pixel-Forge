# The Last Revenge

A first-person survival horror game in the Hollis family house, built from the Pixel-Forge GLB assets and Godot 4.

## Play

Open `project.godot` in Godot 4.3 or newer and run the project. Run `git lfs pull` first so the large GLB assets are available. The game begins in the underground tunnel; search the house, then escape through that same tunnel with the Devil's Bible.

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Look |
| Shift | Sprint (noisy) |
| C | Crouch (quiet) |
| F | Toggle flashlight |
| E | Interact, collect items, flip switches, use doors |
| R | Use the walkie-talkie to contact Ada |
| Q | Use one collected blood bag to restore health |
| Left mouse or T | Swing the bloody baseball bat |
| Esc | Pause |
| G | Open the asset gallery from the menu |

## Story and missions

Abel Crane is Nora's father and the Butcher. Mira, his wife, haunts the horror corridor. Ada, Nora's younger sister, is the blood-stained ghost in the vintage living room. The translucent Horror Girl, Lily, holds the key to the slaughterhouse. The porcelain doll cries, the street rat bites, and the Butcher hunts by sight and sound.

Find the bloody bat, contact Ada, defeat Lily for Father's key, collect Mira's corridor key, take the Devil's Bible, and return to the tunnel. Optional spirit missions let you free Ada and Mira with the bat. Blood bags are collected and stored until Q is pressed; raw meat can be eaten for a smaller heal.

Room lights begin on. Each room switch controls its lights; turning a light on shorts the whole house. The main breaker restores power, and every power change draws Lily into view. The rusted fan creaks, the wall clock ticks, Pearl cries, the rat squeaks and bites, and the walkie uses radio static and ghost dialogue.

The slaughterhouse includes a meat-hook rail, hanging pigs, and blood-splashed walls. A wooden toilet sits in the bathroom, with a vintage parlor for Ada and a haunted corridor for Mira.
